# Data partnership outline for PATH building owners

The following **requested** materials are needed to make the PATHway Toronto pilot operational and independent of copyrighted third-party venue maps.

1. Written licensed permission to publish/reuse indoor floor geometry, descriptions, entrance positions and routing centerlines (including derived data, API output and 3D views).
2. A single building or floor first: geo-referenced corridors, retail shop footprints, public areas, washrooms, exits and exact accessible entrances.
3. Floor levels with building-specific nomenclature and conversions (e.g. -0.5 mezzanine to B1 and neighbouring underground levels).
4. Stairs, escalators, elevators, ramps and one-way access; accessible dimensions, security/restriction rules, hours and closures.
5. Periodic updates and field validation with a point of contact for correction requests.

Acceptance: A visitor can select two surveyed points, verify accessibility preferences, obtain an actual corridor-following route with turn/floor instructions, visually match each turn on site, and receive a clearly labelled alternative if an indoor route is impossible.
