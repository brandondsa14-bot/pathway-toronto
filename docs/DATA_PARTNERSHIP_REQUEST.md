# Data partnership / permission outreach (draft)

**Subject:** Request for licensed indoor PATH floor-plan and wayfinding data — PATHway Toronto pilot

Hello,

I'm developing PATHway Toronto, a research-stage navigation prototype that aims to improve wayfinding through Toronto's downtown PATH. I'm exploring a limited pilot in partnership with property managers and transit operators rather than reproducing existing map graphics or unlicensed indoor data.

Would your team be open to discussing access to **current interior corridor geometry, floor plans, access points, vertical transitions, and location directories** for your portion of the PATH, along with permission to process these into an interactive map and routing graph? Ideally, any agreement would specify authorized display, derivative use, attribution, publication rights, accessibility data, permitted hosting, changes/closures and ongoing update responsibilities.

The prototype already has a source-gated map and route engine, but it intentionally provides no live indoor directions without accurate licensed geometry and on-site validation. I would be happy to share a short technical demonstration and propose a small, independently verified pilot area.

Thank you for considering this request.
